# School photography

The first version uses individual Unsplash image URLs in `src/App.jsx` so the layout works without an image collection. Before launch, replace them with approved, locally hosted school photography and update the `photos` paths to `/images/...`.

Suggested filenames:

- `hero-students.jpg`
- `school-campus.jpg`
- `early-years.jpg`
- `primary-school.jpg`
- `middle-school.jpg`
- `high-school.jpg`
- `co-curricular.jpg`
- `admissions-students.jpg`

Use photos the school has permission to publish, especially where students are identifiable.
